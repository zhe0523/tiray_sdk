# TiRay 43108 SDK 客户集成手册

## 1. 交付内容

客户版本只使用 `include/tiray_sdk.h`、`include/tiray_sdk.hpp` 和安装后的 `tiray::tiray_sdk` 库，不需要接触 `src/`。RS422 协议和 PCIe BAR0 解析均由 SDK 内部完成。

## 2. 初始化

```cpp
tiray_sdk_config_t config;
tiray_sdk_default_config(&config);
config.rs422_device = "/dev/ttyWCH0";
tiray::Sdk sdk(&config);
tiray_status_t result = sdk.open();
if (result != TIRAY_STATUS_OK) {
    std::cerr << tiray_status_string(result) << std::endl;
    return 1;
}
```

默认通信参数是 115200、8N1、无流控、500 ms 响应超时、最多重试 2 次。

## 3. 推荐的业务流程

1. `open` 后执行 `ping` 和 `status`；
2. 读取 Static/Dynamic 配置；
3. 需要手动上图时调用 `start_static`，图像通过 PCIe 接收；
4. Dynamic 运行前设置 `cycle` 和 Step 表，`cycle` 不允许为 0；
5. 模板制作使用 Offset/Gain 流程接口，并轮询 `calibration_status`；
6. 程序退出前停止 Dynamic、停止 PCIe 线程并关闭 SDK。

## 4. 高层配置接口

优先使用 `tiray_get_static_config`、`tiray_set_static_config`、`tiray_get_dynamic_config` 和 `tiray_set_dynamic_config`，不要在客户程序中直接组装 item ID。

Dynamic 配置结构包括：cycle、图像起始/结束地址、启动/轮询/停止超时，以及 10 组 `step_high/step_low`。下发前 SDK 会校验 `cycle != 0` 和起始地址不大于结束地址。

## 5. PCIe 图像内存

客户分配图像缓存，SDK 将一帧 RAW16 图像复制到该缓存中。缓存容量至少为 `rows * columns * 2` 字节，接收完成后由客户负责处理和释放。SDK 不保存客户缓存指针，也不负责图像长期存储。

建议使用独立接收线程；收到一帧后立即复制或交给图像队列，不要在 PCIe 接收线程中执行耗时图像处理。`image_type=0` 是正常图像，`image_type=1` 是模板上传图像。

如果不希望客户自行维护接收线程，可以使用 `tiray_pcie_start` 注册 `tiray_pcie_frame_callback_t`。回调中的 `frame->data` 只在回调期间有效，必须在回调中复制到客户自己的队列；停止时调用 `tiray_pcie_stop`，SDK 会等待后台线程退出。

## 6. 错误处理

所有 API 都返回 `tiray_status_t`，使用 `tiray_status_string` 转换为可读文本。`TIRAY_STATUS_DEVICE_ERROR` 代表设备已收到请求但拒绝执行，需结合设备状态和设备日志判断；`TIRAY_STATUS_TIMEOUT` 代表 RS422 在配置的时间内没有收到匹配响应；`TIRAY_STATUS_PROTOCOL_ERROR` 通常表示帧、BAR0 或 DMA 元数据异常。

## 7. 权限和系统依赖

RS422 需要访问 `/dev/ttyWCH0`，PCIe 需要访问 `/dev/idma0_event_0`、`/dev/idma0_c2h_0` 和 BAR0 `resource0`。正式系统应使用 udev 规则授予应用用户权限，不建议长期使用 root 运行客户程序。

## 8. 最小集成验证

```bash
./tiray_sdk_hardware_test --port /dev/ttyWCH0
```

进入交互模式后依次执行 `ping`、`status`、`config_get 5`、`static`。终端出现 `[PCIe]` 日志即表示图像已从 PCIe 接收。

## 9. 生成客户交付包

在麒麟服务器执行：

```bash
./scripts/package_sdk.sh 0.1.0
```

脚本会自动配置 Release 构建、编译、运行 CTest、安装头文件/库/文档，并生成 `dist/tiray-sdk-0.1.0-<arch>.tar.gz`。
