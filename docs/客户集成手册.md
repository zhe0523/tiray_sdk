# 内部说明：客户集成手册

客户可见的集成手册在 `docs/customer/`，随 `package_sdk.sh` 安装。

请勿再把本节或本文件打进客户包。修改对外叙述时只改 `docs/customer/`。

## 打包（仅内部）

```bash
./scripts/package_sdk.sh 0.1.0
```

确认 `dist/tiray-sdk-*/share/doc/tiray_sdk/` 中：

- 有 `README.md`、`快速开始.md`、`客户集成手册.md`、`API参考.md`、示例
- **没有** 仓库根 `README.md`（研发路线）、没有 `D:\Tiray` 路径、没有 INTERNAL_BUILD 教程
