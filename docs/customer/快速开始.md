# 快速开始

## 1. 安装交付包

在目标麒麟/Linux 机器解压发行包（名称类似 `tiray-sdk-0.1.0-x86_64.tar.gz`）：

```bash
tar -xzf tiray-sdk-0.1.0-$(uname -m).tar.gz
sudo cp -a tiray-sdk-0.1.0-$(uname -m)/. /usr/local/
```

安装前缀也可改为任意目录，只要 CMake 能找到 `lib/cmake/tiray_sdk`。

包内通常包含：

```text
include/tiray_sdk.h
include/tiray_sdk.hpp
lib/libtiray_sdk.a
lib/cmake/tiray_sdk/
share/doc/tiray_sdk/          # 本文档
```

## 2. 系统权限

当前用户需要对下列节点有读写权限（名称以现场为准）：

| 用途 | 默认路径 |
|---|---|
| RS422 | `/dev/ttyWCH0` |
| PCIe 事件 | `/dev/idma0_event_0` |
| PCIe 数据 | `/dev/idma0_c2h_0` |

不要用长期 root 跑业务程序。udev 示例见同目录 `99-tiray.rules` 和《系统依赖与权限》。

## 3. CMake 接入

```cmake
cmake_minimum_required(VERSION 3.16)
project(my_app LANGUAGES CXX)
find_package(tiray_sdk REQUIRED)
add_executable(my_app main.cpp)
target_link_libraries(my_app PRIVATE tiray::tiray_sdk)
target_compile_features(my_app PRIVATE cxx_std_17)
```

```bash
cmake -S . -B build -DCMAKE_PREFIX_PATH=/usr/local
cmake --build build
```

纯 C 工程包含 `tiray_sdk.h`，并链接 `tiray_sdk` 与 `pthread`（`-ltiray_sdk -lpthread`）。

不安装到系统目录时：

```bash
PREFIX="$PWD/tiray-sdk-0.1.0-$(uname -m)"
cmake -S . -B build -DCMAKE_PREFIX_PATH="$PREFIX"
```

## 4. 编译随包示例

文档目录里有 `examples/customer_demo.cpp` 和 `示例CMakeLists.txt`：

```bash
DOC=/usr/local/share/doc/tiray_sdk
cp "$DOC/examples/customer_demo.cpp" .
cp "$DOC/示例CMakeLists.txt" CMakeLists.txt
cmake -S . -B build -DCMAKE_PREFIX_PATH=/usr/local
cmake --build build
./build/tiray_customer_demo /dev/ttyWCH0
```

参数为 RS422 设备节点，缺省 `/dev/ttyWCH0`。

## 5. 最小连通性检查

```cpp
#include "tiray_sdk.hpp"
#include <iostream>

int main() {
    tiray_sdk_config_t config;
    tiray_sdk_default_config(&config);
    config.rs422_device = "/dev/ttyWCH0";
    tiray::Sdk sdk(&config);
    tiray_status_t st = sdk.open();
    if (st != TIRAY_STATUS_OK) {
        std::cerr << tiray_status_string(st) << std::endl;
        return 1;
    }
    st = sdk.ping();
    std::cout << tiray_status_string(st) << std::endl;
    return st == TIRAY_STATUS_OK ? 0 : 2;
}
```

`open` 失败先查串口和 udev；`ping` 超时先查 115200 8N1 和下位机进程。收图流程见《客户集成手册》；对不上号见《常见问题》。
