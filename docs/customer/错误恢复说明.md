# 错误恢复说明

| 返回值 | 处理建议 |
|---|---|
| `OK` | 继续流程 |
| `TIMEOUT` | 保持设备状态不变时可重试；连续出现时重新打开 RS422 |
| `BUSY` | 等待当前采集或模板任务完成后再操作 |
| `DEVICE_ERROR` | 读取状态并查看设备日志，不要盲目重复硬件动作 |
| `PROTOCOL_ERROR` | 检查 SDK/下位机版本、PCIe BAR0 和 DMA 元数据 |
| `IO_ERROR` | 检查串口、PCIe 设备节点和用户权限 |
| `INVALID_ARGUMENT` | 检查缓冲区容量、地址范围和模板参数 |

模板任务失败时先调用对应的 `cancel`，确认状态回到空闲后再开始下一轮。Dynamic 异常时先执行 `stop_dynamic`，再读取状态。
