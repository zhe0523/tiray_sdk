# TiRay 43108 客户集成手册

本 SDK 仅支持 Linux/Kylin。客户使用 C/C++ 业务接口，不需要访问 RS422 协议和 FPGA BAR0 内部实现。

## 初始化

```cpp
tiray_sdk_config_t config;
tiray_sdk_default_config(&config);
config.rs422_device = "/dev/ttyWCH0";
tiray::Sdk sdk(&config);
if (sdk.open() != TIRAY_STATUS_OK) return 1;
```

## 推荐流程

1. `ping` 和 `status`；
2. 使用 `get_static_config/get_dynamic_config` 读取配置；
3. 使用 `start_static` 触发手动上图，或使用 Dynamic 启停接口；
4. 模板制作过程中轮询 `calibration_status`；
5. 通过 PCIe 回调接收图像；
6. 停止 PCIe、关闭 RS422、销毁 SDK。

## PCIe 内存责任

SDK 不维护客户级图像队列，也不替客户申请长期缓存。回调中的 `frame->data` 只在回调期间有效，客户必须复制到自己的缓存或队列，缓存容量至少为 `rows * columns * 2` 字节。客户负责自己的缓存释放、队列深度和丢帧策略。

`examples/customer_demo.cpp` 是完整示例：客户使用自己的 `std::vector<uint8_t>` 保存最新帧，并使用互斥锁保护访问。

## 配置

优先使用高层接口 `tiray_get_static_config`、`tiray_set_static_config`、`tiray_get_dynamic_config` 和 `tiray_set_dynamic_config`。Dynamic 的 `cycle` 必须大于 0。

## 错误处理

所有接口检查 `tiray_status_t`，使用 `tiray_status_string` 获取文本。设备忙时等待任务结束；模板失败时先取消任务；Dynamic 异常时先停止再读取状态。
